# Atlas Studio — One Studio. Every Print.

Foundation work in progress. This repository contains the real Bambu Studio C++
application, not a replacement UI. The application is still upstream-branded.
No Windows executable has been built or tested in this development session.

Read [FOUNDATION.md](FOUNDATION.md) for findings and status and
[WINDOWS.md](WINDOWS.md) for the exact next steps to run the prepared build.

Baseline gate: Windows compilation, install staging and upstream CTest must pass
before branding or Centauri Carbon profile changes begin. The baseline artifact
is for development evaluation; it is not an Atlas Studio release.
